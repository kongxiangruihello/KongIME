已有 KongIME

本次将系统客户端更新至 0.26.0。安装前可在旧版“设置 → 版本状态”查看当前版本，并使用“备份全部配置”另存一份。

个人数据会保留

安装程序只更新客户端，不清空个人词库、短语、配置或 Rime 学习记录。旧客户端会先复制到本机备份目录；这份程序备份不能代替个人数据备份。

学习词频需在“备份与恢复”中单独备份；普通配置备份不包含它。

首次安装

安装完成后在系统键盘设置中添加 KongIME，再导入词库并应用配置。

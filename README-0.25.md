# KongIME 0.25 测试版

KongIME ---- 自由输入，专注表达。

开发者：孔祥瑞。适用于 Apple Silicon Mac、macOS 13 及以上。

本版更新
1. 中英文切换提示：切换或激活输入法时短暂显示“中”或“EN”，可在设置 → 个性化 → 输入习惯中关闭。菜单栏继续只显示 K。
2. 候选词屏蔽：右键候选，选择“不再推荐这个词”。按完整词语匹配，对全拼、简拼和混合拼音生效，不影响包含该文字的其他长词。设置 → 我的词语 → 快捷排序，筛选“已屏蔽”，可取消屏蔽。下次输入生效；配置备份和完整备份都包含屏蔽记录。
3. 成对标点：中文、英文分别开启，默认关闭。支持括号和引号，光标留在中间；退格删除空的一对。没有拼音组合、没有选中文字且应用支持文本定位时才接管。英文单词中的撇号保留正常输入。中文状态使用英文标点时仍由中文开关控制。
4. 完整迁移备份：设置 → 备份与恢复 → 完整迁移备份。一份 JSON 保存配置、词库、短语、回收站、场景、快捷排序、屏蔽记录和学习词语及使用次数。恢复前展示差异，校验文件完整性；恢复后核对配置和学习词频。中途失败或下次启动发现未完成操作时，恢复操作前数据；也可下载恢复前完整备份，重新预览恢复。

安装
解压并打开“安装KongIME.pkg”。安装后保存工作，注销并重新登录 macOS。打开输入法菜单“设置…”，确认设置、已安装、正在运行均为 0.25.0，再保存并应用。
安装保留已有个人数据。新开关保存并应用后生效；完整迁移必须安装并启动 0.25 客户端。

换机
旧 Mac 保存配置，结束正在输入的内容，点击“准备完整备份”，再点击“下载完整备份”。可将文件存入 iCloud Drive，等待系统上传完成。
新 Mac 安装同版输入法后，选择“预览完整备份”，检查差异并确认恢复。过程中暂停输入；恢复后保存并应用，在日常应用中试打。
备份不包含应用程序、本机最近中英文状态、未保存草稿或完整输入历史。学习数据迁移词语及使用次数，近期排序可能继续调整。普通配置／iCloud 快照仍不含学习词频，请区分入口。

验证边界
使用临时目录和真实 Rime 数据库验证完整迁移、校验失败、预览过期、配置变化、故障回退、进程中断恢复及空词库恢复。macOS NSTextView 验证成对标点、光标位置、空对删除和 emoji 前后的 UTF-16 位置。
本轮没有替换正在运行的系统输入法；跨应用提示及不同编辑器的标点兼容性仍需安装后实际确认。两台物理 Mac 和 iCloud 上传／下载恢复未现场验证，iCloud 自动备份继续关闭。
客户端为本地签名开发构建，安装包未进行 Developer ID 签名或 Apple 公证。

# KongIME 0.26

KongIME ---- 自由输入，专注表达。

开发者：孔祥瑞。Apple Silicon Mac，macOS 13 及以上。

## 本版更新

1. 应用输入兼容性：可为某个应用单独停用成对标点，同时保留原来的中文、英文或记忆模式。新增“跟随客户端默认”，无须为了关闭标点强制改变语言。
2. 成对标点：选中文字后输入左括号或引号，会包裹选区；输入光标后已有的右括号或引号会跳过。支持中文、表情与多行选区；在标准 macOS 文本控件中一次撤销即可还原本次包裹。具体撤销分组由编辑器决定。
3. 恢复后应用：在“备份与恢复”顶部点击“应用并检查”，编译当前已保存配置，验证全拼、简拼，再请求输入法加载。失败可重试。完整迁移新增恢复前备份的预览回退入口；确认后才替换数据。
4. 手动更新：设置里的“版本更新”可检查 GitHub 发布的安装包；可选包含测试版。只读取公开版本信息，下载和安装由用户手动完成。

## 安装与使用

解压后打开“安装KongIME.pkg”。安装完先保存其他工作，再注销并重新登录 macOS，确保新版输入法接管。在系统设置的输入法列表中选择 KongIME，打开菜单中的“设置”，点击“保存并应用”。

菜单栏显示 K，方案为 KongIME 全拼。保留既有词库、短语、候选偏好与学习数据；建议升级前保留个人备份。

在设置中搜索“兼容”，选择应用并设置初始语言、是否停用成对标点。保存应用设置后仍需应用到输入法。成对标点的中文、英文总开关位于“输入习惯”，默认关闭。

恢复数据成功不等于正在运行的输入法已加载。应用与检查通过后，在试打区输入 nihao、nh、ni'h 验证；关闭简拼时检查会明确跳过简拼项。恢复后再次修改配置，应用的是当前已保存的内容。

## 适用范围

成对标点仅在无拼音组合、应用支持文档文本定位时工作；包裹选区最大 100000 个 UTF-16 单元。密码框、不支持定位或具有特殊文本模型的编辑器可能不提供此功能，可按应用停用。

本版为测试版，使用本地临时签名，尚无 Developer ID 签名和 Apple 公证。跨应用实测与两台物理 Mac 的完整迁移尚待验证，iCloud 自动备份仍保持关闭。完整验证情况见源码内 VALIDATION-0.26.md。
